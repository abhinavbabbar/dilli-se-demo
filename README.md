# Dilli Se – app demo

Live demo of the Dilli Se community app for the Delhi NCR community in Dubai:

**https://abhinavbabbar.github.io/dilli-se-demo/**

Open it in any phone browser. Tap **I'm already a member** to sign in as the demo user, or **Request to join** to try the join and approval flow.

This repository only holds the built web page. The app source is in a private repository.
